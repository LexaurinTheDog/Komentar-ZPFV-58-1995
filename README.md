# Komentář k zákonu č. 58/1995 Sb., o pojišťování a financování vývozu se státní podporou

Otevřený komentář k zákonu o pojišťování a financování vývozu se státní podporou — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; exportní pojišťovna, pojištění vývozních úvěrových rizik, záruky, podpořené financování, systém dorovnávání a ručení státu.
